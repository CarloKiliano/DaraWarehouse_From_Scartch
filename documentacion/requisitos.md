# 📋 Requisitos del proyecto

## 1. Construir el almacén de datos (ingeniería de datos)

**Objetivo:** crear un almacén de datos moderno en SQL Server que junte los datos de ventas
para poder hacer reportes y tomar decisiones.

**Especificaciones:**

- **Fuentes:** importar datos de dos sistemas (ERP y CRM) que vienen como archivos CSV.
- **Calidad de datos:** limpiar y corregir los problemas de calidad antes de analizar.
- **Integración:** combinar ambas fuentes en un solo modelo fácil de consultar.
- **Alcance:** solo la versión más reciente de los datos; no se guarda historial.
- **Documentación:** documentar el modelo para que lo entiendan tanto el negocio como los analistas.

## 2. Análisis y reportes (análisis de datos)

**Objetivo:** con consultas SQL, obtener información sobre:

- **Comportamiento de clientes**
- **Desempeño de productos**
- **Tendencias de ventas**
